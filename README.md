# Yapılacaklar Listesi (Python)

Python ile geliştirilmiş, konsol tabanlı basit bir yapılacaklar listesi uygulaması.
Amaç: Python'da sınıf yapısını, listeleri ve kullanıcı girdisi kontrolünü pratik etmek.

## Özellikler
- Görev ekleme
- Görevleri listeleme
- Görev düzenleme (onay sorusuyla)
- Görev silme (onay sorusuyla)
- Hatalı girişlere karşı kontrol (boş görev, geçersiz sıra numarası)

## Kullanılan Teknolojiler
- Python
- Sınıf yapısı (OOP)

## Çalıştırma
python main.py

## Geliştirme Fikirleri
- Görevleri dosyaya kaydetme ve açılışta yükleme
- Görevleri tamamlandı olarak işaretleme
